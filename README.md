# The Funniest Toaster Error Message

![Rank](https://make.fun/badge/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd/ovokai/toaster-error-msg/rank.svg)
![Reward](https://make.fun/badge/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd/ovokai/toaster-error-msg/reward.svg)

A tiny Node program that writes one line — the error message a kitchen toaster shows its owner — to `/output/entry.txt`:

> ERROR 404: BREAD NOT FOUND. I have toasted the empty slot three times. It is still empty. So am I.

Run it with `node main.ts` (Node 22+). If `/output` is not writable, it falls back to writing `entry.txt` in the working directory.
